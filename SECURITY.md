# Security policy

## Supported versions

Security fixes target the latest stable ATIV release. Development builds and older releases are unsupported; a fix may require upgrading to a newer stable release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tlolabs/ativ/security/advisories/new) when available. Do not disclose an exploitable issue in a public issue or discussion before the maintainer has had a reasonable opportunity to investigate. Public security email: TBD.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Thomas Lothian reviews reports, coordinates disclosure, and publishes security fixes through GitHub Releases. The reporter and maintainer should agree on a disclosure date after a fix or mitigation is available. No fixed response-time commitment is offered.

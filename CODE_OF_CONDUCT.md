# Code of conduct

ATIV adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to project spaces and to public conduct when representing the project.

Thomas Lothian is responsible for enforcement. Report conduct concerns privately through GitHub to the maintainer where possible. Dedicated conduct contact: TBD. Reports will be reviewed confidentially, with action based on the Contributor Covenant enforcement guidelines.

# Release integration status

ATIV's native workflow builds and verifies macOS arm64 and Intel, Windows x64 and ARM64, and Linux x64 and ARM64 independently. A separate publisher watches first-party push runs and publishes a target as soon as its native package, launch, media and host-evidence steps and artifact upload pass. It checks the Actions artifact digest, package bytes, target architecture, host report and release asset digest before publication, then verifies the public download. Main pushes create immutable development prereleases without a manual tag; annotated version tags continue to create stable releases with provenance attestations. Failed targets remain absent from the release and visible in Actions and the consolidated CI/CD issue. Unsigned direct downloads do not enter the signed automatic-update feed.

Direct downloads may be unsigned. Signing and notarization can be requested separately when configured. Authenticated updater feeds retain their signature, installed-key, and upgrade verification requirements; this direct-download path does not generate or alter signed update metadata.

The previous all-target application acceptance ledger and signed-package promotion process is [historical](historical/release-integration-before-nonblocking.md). Its pending evidence is not presented as current qualification. Existing tags and published asset bytes remain immutable.

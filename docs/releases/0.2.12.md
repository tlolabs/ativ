# ATIV 0.2.12

Release date: November 19, 2026. Annotated source tag: `v0.2.12`.

- The engine accepts native path arguments and reports invalid text arguments
  through its structured error protocol.
- Artwork classification skips cancelled work and handles Unix named pipes
  without blocking before rendering.
- Automatic JPEG classification uses a faster buffered marker search and
  retains conservative handling of ambiguous or multi-image containers.

In two paired runs of the production classifier with synthetic 1–32 MiB JPEG
marker streams, classification was 3.4–4.1× faster. The 8 MiB fixture with
stuffed markers went from 3.05 to 0.86 milliseconds in the first run. These
measurements cover classification before export encoding.

The Rust workspace passed 50 tests, with five optional benchmarks ignored.
Gemini and Copilot stopped during initialization in the implementation audit,
so independent audit coverage remains incomplete.

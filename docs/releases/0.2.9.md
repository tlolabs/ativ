# ATIV 0.2.9

Release date: November 11, 2026. Annotated source tag: `v0.2.9`.

This release integrates AVID Core 0.3.3 at immutable commit
`8e27a86ec106028d93130de35a35c0eeda7a9ce3`. The unmodified checked-in Rust
snapshot and separately verified Apple archive make builds independent of that
commit's upstream publication. The independently authenticated FFmpeg/FFprobe
platform pins remain unchanged. See the [capability audit](../core-0.3.3-integration.md).

The workspace, engine, updater and Qt presentation version are 0.2.9. Caption
defaults now come from Core. Shared rendering, transcription and safety remain
Core-backed; ATIV retains its native UI, process/document orchestration, signed
runtime validation and animated-caption presentation.

## Checks and limits

Release checks passed: 44 Rust workspace tests (five optional benchmarks ignored),
strict Clippy and formatting, 88 configured Python tests, the 71-file source
snapshot verifier, dependency inventory and 24 native offscreen Qt workflow tests
against the signed 0.2.9 engine. Original integration checks and their exact
commands remain in the capability audit. Release logs and artifact evidence are
retained locally under task `ativ-core-033-20261110-01/release-0.2.9`.

The release continuation receives a second Gemini audit because it adds version
metadata and the signed-helper validation repair. It retains the original task
ID, baseline and review history; the earlier accepted report remains associated
with its own source hash. Exact review hashes and Codex assessments are recorded
outside the repository with that task.

Only native macOS arm64 is qualified for this direct download. Intel macOS,
Windows and Linux packages are absent rather than represented as verified.
The main app remains macOS 13+; local inference requires Apple silicon/macOS 14+.
Full inference/accuracy, minimum-OS execution and interactive accessibility were
not verified; no model weights were downloaded.

The direct-download release does not promote a new authenticated update feed or
change the existing GitHub Latest release used by its stable endpoints. Existing
public trust keys, signed feeds, publication permissions and weekly diagnostic
smoke CI are preserved. No archived workflow is enabled or dispatched.

# ATIV 0.2.11

Release date: November 16, 2026. Annotated source tag: `v0.2.11`.

This patch release improves static-image export speed, transcript opening and
runtime verification, and fixes cancellation and audio-selection handling.

- Static JPEGs containing EXIF thumbnails use the cached-frame rendering path.
  Multi-image and ambiguous containers retain conservative playback handling.
- Transcript documents open without decoding their full canonical payload twice.
- Cached platform runtimes avoid duplicate full-payload hashing while retaining
  provider attestation, provenance and integrity checks.
- Packaged-runtime verification responds to cancellation between hash chunks and
  directory entries.
- Completed native engine requests release their cancellation state. Superseded
  Qt audio probes restart correctly for same-path and A → B → A selections.

The recorded macOS arm64 workloads measured JPEG export at 0.953 → 0.244 seconds,
transcript opening at 134.4 → 73.7 milliseconds, and local runtime verification at
57.5 → 37.9 milliseconds. These measurements used the preceding 0.2.10 development
build of the same implementation; the release continuation changes version and
release metadata only. The JPEG comparison verified 900 decoded frames and
timestamps against an equal-duration control. The existing explicit PerFrame
path can retain a variable silent video tail. Runtime timings mocked remote
provider calls to isolate local verification cost.

Implementation checks passed locally: 47 Rust workspace tests, 93 Python tests,
51 native Swift tests, 25 Qt workflow tests, eight current-engine tampering tests,
real-media integration, formatting and strict Clippy. The version continuation
reran these checks against 0.2.11, confirmed the engine and compiled Qt version,
and verified the lockfile and dependency inventory before tagging the tested
source commit.

Gemini profile `gemini` selected `gemini-3.8-flash-high`; Copilot selected
`gpt-5.6-sol`. Both returned partial source reports. Gemini's sole finding
concerned implementation not yet being done during the explicitly ordered
pre-implementation audit; it did not identify a code defect. Copilot reported no
concrete findings. Independent backend identities were not exposed; attribution
is limited to CLI selections. The review runner excluded media, binary assets
and some other non-code files. Its isolated Cargo check failed because a required
vendored license file was excluded; the live-tree Rust suite passed separately.
Full external audit coverage remains incomplete.

This release publishes source only. No native package from this revision is
qualified or uploaded. Native Windows/Linux execution, macOS Intel execution and
interactive accessibility were not verified. Developer ID signing, accepted
notarization and final-package verification remain required for a distributable
macOS app. The existing GitHub Latest release and authenticated update feeds are
preserved. Weekly CI and archived workflows are unchanged.

# Support

- **Bugs:** Open a [GitHub issue](https://github.com/tlolabs/ativ/issues/new) with the ATIV version, platform, steps to reproduce, and relevant local diagnostics.
- **Feature requests:** Open a GitHub issue describing the workflow and desired result.
- **Usage questions:** Search the [README](README.md) and [documentation](docs/BUILDING.md), then open a GitHub issue if the answer is missing.
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md) and report privately.

Support is community based; there is no guaranteed response time. Public support email: TBD.
